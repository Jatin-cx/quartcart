01 | PROJECT VISION

Problem Statement & Project Objectives

Bridging the gap between flat 2D online catalogs and physical luxury retail showrooms.

Limitations of Conventional Online Stores

  • Flat 2D Product Grids: Shoppers cannot inspect product depth, finish, or spatial geometry before buying.
  • Disconnected Cart Flows: Adding products often triggers page reloads or lacks instant visual confirmation.
  • Hardcoded Storefront Themes: Changing brand titles, color palettes, or hero copy requires developer code edits.
  • Unprotected Admin Pages: Prototype dashboards often lack proper role-based authentication gates.

How QuickCart Solves These Challenges

  • Three.js WebGL 3D Showroom: Interactive 360-degree product turntable, 3D floating background, and 3D card tilt physics.
  • Global Slide-Out Bag Drawer: Instant localStorage-synced shopping bag drawer with free shipping progress bar.
  • Live Site & Theme Customizer: Admin can rebrand the store, switch 5 color palettes, and edit hero text live.
  • Multi-Layer JWT + RBAC Security: Hidden navbar link + dedicated Admin Security Gate + requireAdmin middleware.

05 | CHECKOUT & PAYMENTS

Smart Checkout, Promo Engine & Stripe Integration

Seamless order placement, automatic inventory stock deduction, and PCI-compliant payment processing.

Checkout & Order Pipeline (checkout.html)

  • Address Auto-Fill: Pre-fills saved customer address from User profile and validates all shipping fields.
  • Promo Code Engine: Supports promo code QUICK3D (15% instant discount) and automatic complimentary shipping across India on orders over ₹999.
  • Atomic Stock Deduction: Backend verifies product availability in MongoDB and decrements stock upon order creation.
  • Order Confirmation: Generates unique Order ID and saves to customer order history.

Stripe Payment Architecture (routes/payment.js)

  • POST /api/payment/create-intent: Calculates order total in cents and returns a Stripe clientSecret.
  • Stripe Elements UI: Mounts the Stripe Card Element inside checkout.html with real-time validation.
  • POST /api/payment/webhook: Verifies cryptographic Stripe signature and updates paymentStatus to paid.
  • Local Demo Mode: Supports instant test order placement when running in local classroom environments.

06 | SECURITY & AUTHENTICATION

Multi-Layer Authentication & Security Architecture

Enterprise-grade password hashing, stateless JWT sessions, and HTTP security hardening.

Bcrypt Password Hashing (models/User.js)

Passwords are never stored in plain text. Mongoose pre-save hooks automatically hash passwords using bcryptjs with 12 salt rounds, and select: false strips passwords from query results.

Stateless JWT Sessions (middleware/auth.js)

Upon login, the server signs a JSON Web Token (JWT) containing user ID and role (7-day expiry). Protected routes verify the Authorization: Bearer <token> header on every request.

Role-Based Access Control (requireAdmin)

Strict separation between customer and admin roles. Any non-admin account attempting to call an admin endpoint receives an immediate 403 Forbidden response.

Rate Limiting & Helmet CSP (server.js)

express-rate-limit blocks brute-force login attempts, while helmet configures strict Content Security Policy (CSP) HTTP headers.

07 | ADMIN VAULT SECURITY

Secured Owner & Administrator Control Center

Invisible to regular customers and protected by a dedicated 4-layer Owner Authentication Gate (/admin.html).

Layer 1: Hidden Navbar Link

Guests and logged-in Customer accounts never see the Admin Vault button in the navbar. api.js renders it only when user.role === "admin".

Layer 2: Security Gate UI

Visiting /admin.html directly hides the entire dashboard workspace and displays the Restricted Owner & Admin Authentication Vault until verified.

Layer 3: Dual API Middleware

Every management route in routes/admin.js enforces both authMiddleware (401) and requireAdmin (403) on the server.

Layer 4: Master Key & Lock

Supports Owner Master Key (kala_hu_re) for account elevation and a 1-click Lock Vault button to end the session.
